# Support

Use this repository's GitHub Issues for questions, bug reports, and feature
requests. Search existing issues first. Select the matching issue template and
include the publisher version, the Python and Node versions, the operating
system, the exact command, the expected result, and the sanitized error. Attach
a minimal synthetic fixture when you can.

Start with the [quick start](README.md#quick-start-with-docker),
[operations](docs/operations.md), [Docker](docs/docker.md),
[migration](docs/migration.md), [plugins](docs/plugins.md), or the
[documentation index](docs/README.md). Collection, detection, and the evidence
feed belong to the engine's support channel.

Keep credentials, journals, flight archives, private receiver URLs, receiver
locations, and real publisher state out of public reports. Report
vulnerabilities and accidental data disclosures through [SECURITY.md](SECURITY.md).

Support is provided as maintainer time permits, without a guaranteed response
time. This project does not provide an aircraft identification service or verify
who is aboard an aircraft.
